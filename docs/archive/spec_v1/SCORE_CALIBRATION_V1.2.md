# JDSS v1.2.0 점수 재보정 보고서

> **문서 상태: v1.3에 승계된 보정 연구.** 현재 점수표와 매매 규칙은
> [`STRATEGY_V1.3.md`](STRATEGY_V1.3.md)와 루트의 [`strategy.yaml`](../strategy.yaml)이 최종
> 기준이다.

## 결론

JDSS v1.1.2의 등급 경계와 항목별 최대점수는 유지하고, 항목 내부의 원점수 곡선만
재보정했다. 선택된 v1.2.0 곡선은 학습·검증 구간에서 고정한 뒤 2023년 이후 OOS에서
처음 평가했다.

| 항목 | v1.1.2 최대점수 | v1.2.0 지수 |
|---|---:|---:|
| 시장 국면 | 25 | 1.000 |
| 과매도 | 40 | 0.100 |
| 반등 | 20 | 0.125 |
| 거래량 | 10 | 0.025 |
| ATR | 5 | 1.000 |

등급은 `WATCH 76 / B 82 / A 88 / S 92`, 총점 상한은 100으로 종전과 같다. 보정식은
다음과 같으며 반올림은 양의 값에 대해 half-up 방식이다.

```text
보정점수 = 항목최대점수 × (원점수 / 항목최대점수) ^ 지수
```

현재 설정은 원점수와 보정점수를 모두 분석 결과에 남겨, 점수 상승 원인을 감사할 수
있다. 기존 공식 설정은 [`configs/strategy_v1.1.2.yaml`](../configs/strategy_v1.1.2.yaml)에
보존했다.

## 점수 곡선

실제로 발생할 수 있는 대표 원점수의 변환은 다음과 같다.

| 항목 | 원점수 → 보정점수 |
|---|---|
| 과매도 | 0→0, 6→33, 10→35, 13→36, 20→37, 26→38, 30→39, 40→40 |
| 반등 | 0→0, 5→17, 10→18, 15→19, 20→20 |
| 거래량 | 0→0, 2→10, 4→10, 7→10, 10→10 |
| ATR | 0→0, 2→2, 3→3, 5→5 |

이 곡선은 원래 점수표가 과매도와 반등을 동시에 강하게 요구해 전체 표본 최고점이
77에 그쳤던 문제를 해소한다. 다만 거래량은 사실상 `20일 평균 이상인가`를 나타내는
이진 가점으로 바뀌므로 향후 실시간 데이터에서 별도로 관찰한다.

## 연구 절차

- 데이터: yfinance `auto_adjust=True` 일봉, 2011-01-01~2026-08-04
- 대상: TQQQ, SOXL 각 10,000달러, 합산 20,000달러
- 비용: 매수 0.1%, 매도 0.1%, 기본 슬리피지 0.1%
- 체결: 신호 다음 거래일 시가, 추격매수 및 단계별 가격 상한 적용
- 학습: 2011-01-01~2018-12-31
- 검증: 2019-01-01~2022-12-30
- 잠금 OOS: 2023-01-01~2026-08-04

OOS를 열기 전 총 573개 격자 조합을 학습·검증 구간에서만 평가했다. 두 구간 모두
양의 수익이고 각각 체결 4회 이상인 조합만 후보로 인정했다. 연구 실행기와 전체 후보
CSV 생성 방법은 [`scripts/calibrate_scores.py`](../scripts/calibrate_scores.py)에 있다.

견고성 목적함수 1위는 `0.100 / 0.100 / 0.075 / 1.000`이었지만, 사용자가 요청한 수익
극대화를 우선해 학습과 검증 수익이 모두 더 높은
`0.100 / 0.125 / 0.025 / 1.000`을 최종 잠금 후보로 선택했다.

| 후보 | 학습 수익률 | 학습 MDD | 검증 수익률 | 검증 MDD |
|---|---:|---:|---:|---:|
| 견고성 1위 | +27.92% | -11.15% | +13.98% | -6.96% |
| 최종 수익 후보 | **+34.74%** | -14.16% | **+14.36%** | -6.95% |

최종 후보의 학습 체결은 60회, 검증 체결은 38회였다. 인접 후보에서도 비슷한 성과가
나와 단일 파라미터 점의 우연에만 의존하지 않았지만, 이는 과최적화 가능성을 없애지는
않는다.

## 판정과 운영 제한

- v1.2.0은 v1.1.2의 0회 거래 문제를 해소하고 잠금 OOS 및 슬리피지 스트레스를
  통과했다.
- 이 결과는 수익 보장이 아니며, OOS도 약 3.6년에 불과하다.
- yfinance 수정 일봉은 연구용이며 세금, 환전, 금리, 모든 스프레드와 시장충격을
  완전히 반영하지 않는다.
- 자동 손절이 없는 레버리지 ETF 전략이므로 개별 포지션의 급락과 장기 고착 위험이
  포트폴리오 MDD보다 훨씬 클 수 있다.
- 실거래 승격은 하지 않는다. Telegram dry-run, Toss 조회 smoke test, 서버 Python
  3.11 이상 전환, 전진 관찰과 운영자 명시 승인이 남아 있다.

재현 명령:

```bash
.venv/bin/python scripts/calibrate_scores.py select \
  --oversold 0.075,0.10,0.125 \
  --reversal 0.025,0.05,0.075,0.10,0.125 \
  --volume 0.025,0.05,0.075,0.10,0.125 --atr 1.0
.venv/bin/python scripts/calibrate_scores.py oos \
  --oversold 0.10 --reversal 0.125 --volume 0.025 --atr 1.0
.venv/bin/jdss backtest --symbol ALL --start 2011-01-01 --end 2026-08-04 \
  --slippage 0.001 --output reports/v1.2_full.json
```
