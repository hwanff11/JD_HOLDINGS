# JDSS 전략 가이드와 발전 이력

현재 개발 계약은 **JDSS-3.1.0-TWIN-H40-S3**다. 정확한 수치와 실행 규칙은 [`JDSS_FINAL_SPEC.md`](JDSS_FINAL_SPEC.md)와 루트 `strategy.yaml`을 기준으로 한다.

## 현재 주력: V3.1 TWIN-H40-S3

V3.1은 월간 추세 코어와 과매도 반등 부스터를 함께 운용한다. 두 전략이 쓰지 않는 JDSS 관리자금은 SGOV에 둔다.

- QQQ·SOXX 완료 월말 종가 > 각 **6개월 이동평균**: 대응 TQQQ·SOXL 코어 ON
- 코어 목표: 추세가 새로 ON 된 첫 달 **10%**, 다음 달에도 유지되면 **15%**
- 코어 비중 기준: 전체 Toss 계좌가 아니라 **JDSS managed equity**. 개인 현금과 개인 SGOV는 계산에서 제외한다.
- 동일 계좌의 **개인 TQQQ·SOXL 보유는 지원하지 않는다.** 브로커가 같은 티커 수량을 합산하므로 JDSS 원장과 안전하게 분리할 수 없어 Reconciliation이 SAFE_MODE로 전환한다.
- JDSS 부스터: 종목당 자금 상한 `$8,000`(총자금 40%). 현재 3단계 누적비중이 90%이므로 정상 한 사이클의 최대 신규투입은 `$7,200`(총자금 36%)
- 부스터 매수: **3단계 40% → 70% → 90%**, 최초 체결가 대비 -2% / -5% 추가매수
- 익절: 평단 +4%에서 약 30%, +10%에서 잔량
- TP1 이후 시간 제한 잔여청산은 비활성화
- 재매수와 자동손절은 비활성화
- 코어·부스터 매수: Telegram 2단계 승인
- 코어 위험축소 매도: 자동
- 잔여자금: JDSS managed cash/관리 SGOV, 현금 버퍼 `$250`
- 모든 BUY는 중앙 주문 게이트에서 JDSS managed cash와 미체결 BUY 예약액을 다시 확인하므로 계좌에 개인 현금이 더 있어도 전략한도를 넘겨 쓰지 않는다.
- 코어 승인 직전에는 신호 당시 계획주수와 현재 잔여 목표주수 중 더 작은 값을 상한으로 다시 계산한다.
- live는 계속 잠금 상태다.

이번 변경은 2011년 이후 동일 조건 연구에서 기존 V3.0 대비 수익과 위험조정 성과가 함께 개선된 후보를 정식 적용한 것이다. 연구 기준 비교에서 V3.0은 CAGR 14.05%, MDD -28.29%, Sharpe 0.835, Sortino 1.004였고, 채택 후보는 CAGR 18.81%, MDD -26.04%, Sharpe 0.940, Sortino 1.197이었다.

## 현재 운영 회계·재시작 원칙

- managed cash는 초기 `$20,000`에서 JDSS 주문의 실제 누적 체결과 설정 수수료만 반영해 계산한다.
- 닫힌 사이클의 실현손익도 다음 재시작 뒤 managed cash에 유지된다.
- SGOV는 `managed cash + JDSS 관리 SGOV 시장가치 - $250` 범위만 운용하며 기존 개인 SGOV를 자동 편입하지 않는다.
- 모든 BUY는 현금검사와 주문예약을 하나의 SQLite `BEGIN IMMEDIATE` 트랜잭션으로 처리해 동시 실행에서 같은 현금을 중복 예약하지 않는다.
- 체결 0인 증명 가능한 DRY 미체결 주문만 cold restart에서 자동 복원한다.
- DRY 주문 sequence는 현재 미체결뿐 아니라 과거 완료 주문을 포함한 전체 주문이력의 최대 번호 이후로 이어간다.
- `UNKNOWN` 또는 재시작 시점 `PARTIAL_FILLED` 주문은 실제 메모리 브로커 상태를 추정하지 않고 SAFE_MODE에서 확인한다.
- 누적 부분체결을 처리할 때는 이전 누적 체결과의 신규 delta만 잔고·현금에 적용한다.

## 연구에서 제거한 후보

- 6M+10M 이중 확인, 6M+3M slope: 단순 6M보다 열위
- QQQ EMA60 / GREEN-only 부스터 필터: MDD 개선 없이 수익 희생
- Score≥92에서만 45/50% 부스터: 실제 노출 변화 없음
- 부스터 45~50%: 위험조정 성과 개선이 거의 포화
- TP2 +8%: +6%와 +10% 사이에서 우월하지 않음
- TP1 이후 20/40거래일 강제 잔량청산: 제한 없음보다 열위
- 4차 추가매수: CAGR +0.14%p 대가로 MDD와 구조 복잡도 증가
