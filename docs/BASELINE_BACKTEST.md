## 판정

따라서 수익률 0%, MDD 0%는 안전성이나 성과를 의미하지 않고 **전략이 한 번도 시장에
진입하지 않았다는 뜻**입니다.

문서가 제안한 진입점수 민감도 `80 / 82 / 85 / 88`도 모두 최고 관측 점수보다 높아
현재 점수표에서는 거래가 발생하지 않습니다. 또한 점수 80을 허용하더라도 기존 노출
구간이 82점부터 시작하므로 사이클 투자한도가 0이 되는 명세상 불일치가 있습니다.

## 운영 결정

- v1.1.2 계산 규칙과 설정은 재현 가능한 공식 기준선으로 보존한다.
- 점수나 진입 기준을 임의로 낮추지 않는다.
- Telegram 연동은 dry-run까지만 허용한다.
- Oracle 실거래 배포와 기존 CCI 봇 종료는 보류한다.
- v1.2 연구에서는 점수 분포, 미래 수익률 단조성, 신호 빈도, OOS, MDD/MAE,
  자금 고착을 함께 검증한 뒤 점수표와 노출 구간을 한 세트로 개정한다.

재현 명령:

