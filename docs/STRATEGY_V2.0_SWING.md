# JDSS 2.0 단타 스윙 전략

## 목표

TQQQ와 SOXL의 큰 일간 변동성을 활용해 짧은 반등을 반복적으로 수익화한다. 종목당 10,000 USD의 고정자금을 사용하며 종목 간 수익 재투자는 하지 않는다.

## 핵심 변경

| 항목 | v1.3.2 | JDSS 2.0 Swing |
|---|---:|---:|
| 최초 진입점수 | 72 | 60 |
| 최초 투자비중 | 30% | 40% |
| 추가매수 비중 | 25/25/20% | 30/20/10% |
| 추가매수 하락폭 | -4/-8/-15% | -2/-4/-7% |
| 추가매수 점수 | 모두 82 | 64/66/68 |
| TP1 | +8% | +3% |
| TP2 | +16% | +6% |
| 추격매수 상한 | +2% | +4% |

반등점수 최소 5, RED 국면 진입 차단, SOXL 3·4차 섹터가드는 유지한다.

## 매매 흐름

1. 점수가 60점 이상이고 반등 조건이 하나 이상이면 4,000 USD로 1차 진입한다.
2. 최초 체결가보다 2% 하락하고 점수가 64점 이상이면 3,000 USD를 추가한다.
3. 최초 체결가보다 4% 하락하고 점수가 66점 이상이면 2,000 USD를 추가한다.
4. 최초 체결가보다 7% 하락하고 점수가 68점 이상이면 남은 1,000 USD를 추가한다.
5. 평균단가보다 3% 상승하면 약 절반을 매도한다.
6. 평균단가보다 6% 상승하면 나머지를 매도한다.

매수는 기존과 동일하게 사용자 2단계 승인이 필요하다. TP1·TP2 매도는 체결된 평단을 기준으로 자동 주문 관리한다.

## 위험과 한계

- 평균적인 보유기간은 크게 짧아졌지만, 급락장에서 일부 사이클은 수백 거래일 동안 고착될 수 있다.
- 장기 종목별 최악 MAE는 TQQQ -16.90%, SOXL -26.35%였다.
- 20~40거래일 강제청산과 12~15% 고정손절도 시험했지만 장기 수익률이 -10.56~+18.01%로 훼손되어 채택하지 않았다.
- 백테스트 성과는 미래 수익을 보장하지 않으며, 현재 서버는 dry_run 상태로 유지한다.
