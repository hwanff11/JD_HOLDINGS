# JDSS V3.1 Telegram Bot 운영 가이드

Telegram 봇은 관리자 Chat ID 한 명만 허용하며 V3.1.0에서도 항상 dry-run으로 동작한다. 코어·부스터 매수는 `검토 → 최종 실행` 두 번의 버튼 승인이 필요하고, 추세 OFF나 목표 초과에 따른 코어 축소 매도만 자동 처리한다.

## 주요 명령

| 명령 | 설명 |
|---|---|
| `/ping`, `/p` | v3.1.0, dry-run, live 잠금 상태 |
| `/dashboard`, `/d` | 계좌·SGOV·종목별 코어와 부스터 통합 요약 |
| `/portfolio`, `/pf` | 6개월 월간 코어 추세·수량·실제비중과 부스터 원가 |
| `/status [종목]`, `/s` | 코어 원장, 부스터 상태와 TP 목표 |
| `/score [종목]` | JDSS H40 부스터의 최신 완결 일봉 점수 |
| `/history [종목] [1~90]` | 최근 부스터 점수 이력 |
| `/signal` | 현재 승인 가능한 코어·부스터 매수 신호 |
| `/sgov` | JDSS 관리 SGOV, 비관리 SGOV, 목표 유휴자금과 SAFE_MODE |
| `/bt` | V3.1 전체 포트폴리오 최근 300거래일 백테스트 |
| `/bt ALL 250` | V3.1 전체 포트폴리오 지정 거래일 백테스트 |
| `/bt TQQQ 100` | 단일 종목 JDSS 부스터 백테스트 |
| `/account` | Toss 미국주식 조회 전용 잔고 |
| `/order` | 미체결 주문 |
| `/errors` | 최근 시스템 이벤트 |
| `/guide` | V3.1 전략과 JDSS 지표 카드 |

## V3.1 메시지 읽기

`월간 코어`는 QQQ 또는 SOXX의 완료 월말 종가가 6개월 이동평균 위인지 보여준다. 추세가 새로 ON 된 첫 달은 대응 TQQQ·SOXL 목표를 10%로 잡고, 다음 월말에도 ON이면 15%로 높여 유지한다. `JDSS H40 부스터`는 55점·반등 5점·RED 차단 규칙을 쓰며 종목별 최대 `$8,000`까지 운용한다. 브로커에는 같은 티커로 합쳐 보이지만 `/portfolio`와 `/status`는 두 원장을 분리한다.

코어 매수 신호에는 다음 항목이 표시된다.

- 기준: 6개월 추세 ON, 첫 활성월 목표 10%, 지속 시 15%
- 실행: 완료 월말의 다음 거래일
- 투자금액, 신호가격, 추격상한
- `실시간 시세로 매수 검토` 버튼

검토 버튼을 누르면 현재가·지정가·정수주·수수료를 다시 계산한다. 최종 조건은 60초 동안만 유효하다. 그 사이 가격, 수량, 세션이 바뀌면 기존 승인을 거부하고 새 검토를 요구한다.

## 부스터 규칙 요약

- 종목별 최대 `$8,000`(초기 총자금의 40%)
- 1·2·3차 40% / 30% / 20%, 누적 40% / 70% / 90%
- 최초 체결가 대비 0% / -2% / -5%
- 모든 단계 55점·반등 5점 이상, RED 차단
- TP1 +4%에서 약 30%, TP2 +10%에서 잔량
- TP1 후 기간 기준 잔여청산 없음
- 재매수·자동손절 없음
- SOXL은 SOXX·SMH EMA60 섹터 가드 적용

## 백테스트 출력

`/bt`는 코어와 부스터가 현금을 공유하고 나머지를 SGOV로 운용하는 통합 결과를 표시한다. 누적수익, CAGR, MDD, Sharpe, 평균노출, 코어·부스터 체결수와 최근 통합 매매를 포함한다. 단일 종목 명령은 해당 JDSS 부스터만 계산하므로 V3.1 전체 성과와 혼동하지 않는다.

## SGOV와 오류 상태

전략 매수에 현금이 부족하면 봇은 JDSS 관리 SGOV만 먼저 매도한다. 체결이 확인되면 최종 승인 버튼을 자동 전송한다. 개인 SGOV는 비관리 수량으로 표시하고 자동 매도하지 않는다. 브로커와 DB 수량 또는 미체결 주문이 다르면 SAFE_MODE가 표시되며 원인을 해결할 때까지 신규매수를 진행하지 않는다.

## 메시지 제약

모든 출력은 Telegram HTML을 사용한다. 동적 값은 HTML escape하고, 버튼 콜백은 관리자 본인만 허용한다. 한 메시지는 4096자 미만이어야 하며 긴 백테스트 결과는 안전한 경계에서 분할한다.
