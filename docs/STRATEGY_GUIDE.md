# JDSS 전략 가이드와 발전 이력

현재 개발 계약은 **JDSS-3.1.0-TWIN-H40-S3**다. 정확한 수치와 실행 규칙은 [`JDSS_FINAL_SPEC.md`](JDSS_FINAL_SPEC.md)와 루트 `strategy.yaml`을 기준으로 한다.

## 현재 주력: V3.1 TWIN-H40-S3

V3.1은 월간 추세 코어와 과매도 반등 부스터를 함께 운용한다. 두 전략이 쓰지 않는 자금은 SGOV에 둔다.

- QQQ·SOXX 완료 월말 종가 > 각 **6개월 이동평균**: 대응 TQQQ·SOXL 코어 ON
- 코어 목표: 추세가 새로 ON 된 첫 달 **10%**, 다음 달에도 유지되면 **15%**
- JDSS 부스터: 종목당 최대 `$8,000`, 총자금 대비 최대 40%
- 부스터 매수: **3단계 40% → 70% → 90%**, 최초 체결가 대비 -2% / -5% 추가매수
- 익절: 평단 +4%에서 약 30%, +10%에서 잔량
- TP1 이후 시간 제한 잔여청산은 비활성화
- 재매수와 자동손절은 비활성화
- 코어·부스터 매수: Telegram 2단계 승인
- 코어 위험축소 매도: 자동
- 잔여자금: SGOV, 현금 버퍼 `$250`
- live는 계속 잠금 상태다.

이번 변경은 2011년 이후 동일 조건 연구에서 기존 V3.0 대비 수익과 위험조정 성과가 함께 개선된 후보를 정식 적용한 것이다. 연구 기준 비교에서 V3.0은 CAGR 14.05%, MDD -28.29%, Sharpe 0.835, Sortino 1.004였고, 채택 후보는 CAGR 18.81%, MDD -26.04%, Sharpe 0.940, Sortino 1.197이었다.

## V3.0에서 V3.1로 바뀐 부분

| 항목 | V3.0.0 | V3.1.0 |
|---|---|---|
| 월간 추세 | 10개월 | 6개월 |
| 코어 | ON 즉시 15% | 첫 ON 10% → 유지 시 15% |
| 부스터 최대 | 종목당 5% / `$1,000` | 종목당 40% / `$8,000` |
| 분할매수 | 4단계 40/30/20/10 | 3단계 40/30/20 |
| 추가매수 | -2/-5/-7% | -2/-5% |
| TP1 | +4%에서 약 50% | +4%에서 약 30% |
| TP2 | +6% | +10% |
| TP1 잔량 시간청산 | 20거래일 뒤 +2% | 비활성화 |
| 재매수 | OFF | OFF |

## 연구에서 제거한 후보

- 6M+10M 이중 확인, 6M+3M slope: 단순 6M보다 열위
- QQQ EMA60 / GREEN-only 부스터 필터: MDD 개선 없이 수익 희생
- Score≥92에서만 45/50% 부스터: 실제 노출 변화 없음
- 부스터 45~50%: 위험조정 성과 개선이 거의 포화
- TP2 +8%: +6%와 +10% 사이에서 우월하지 않음
- TP1 이후 20/40거래일 강제 잔량청산: 제한 없음보다 열위
- 4차 추가매수: CAGR +0.14%p 대가로 MDD와 구조 복잡도 증가
