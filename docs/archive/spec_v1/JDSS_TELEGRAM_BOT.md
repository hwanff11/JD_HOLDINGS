# JDSS Telegram Bot 명세서

> **레거시 v1.1.2 기준선 문서.** 현재 JDSS 2.2 Telegram 메뉴·계좌·SGOV·백테스트
> 동작은 [`../../TELEGRAM_BOT_GUIDE.md`](../../TELEGRAM_BOT_GUIDE.md)를 최종 기준으로 삼는다.

**Telegram Bot Specification(텔레그램 봇 명세) v1.1.2 — 공식 기준선**

---

## 1. 목적

JDSS Telegram Bot은 다음 기능을 제공한다.

- 시장 및 전략 상태 조회
- JDSS 점수 확인
- 매수 후보 확인
- 사용자 승인
- 포지션 확인
- 익절 주문 확인
- 백테스트 결과 확인
- 오류 및 안전모드 상태 확인

가장 중요한 원칙:

> **Telegram Bot은 매매전략을 판단하지 않는다.**

전략 판단은 `Strategy Engine(전략 엔진)`이 수행하고 Telegram은 결과를 표시하고 사용자 승인을 받는다.

---

## 2. 화면 용어 원칙

사용자 화면은 한글을 우선한다.

예:

```text
Regime        → 시장국면
Score         → JDSS 점수
Exposure      → 최대 투자허용액
Anchor        → 1차 기준가격
Reversal      → 반등점수
Entry Stage   → 매수단계
Risk Review   → 장기보유 위험검토
Capital Lock  → 자금고착
```

개발·오류 추적이 필요한 경우에만 괄호 안에 내부 영문 코드값을 표시한다.

## 5. `/dashboard` 대시보드

### 시장

- 시장 국면: GREEN / YELLOW / RED
- 최신 분석 거래일
- 데이터 정상 여부
- 시스템 상태
- 마지막 증권사 정합성 점검시간

### 종목별

- 현재 상태
- JDSS 점수 / 등급
- 현재가
- 평단
- 평가손익률
- 현재 포지션 원가
- 사이클 최대 투자허용액
- 단계매수 누적액
- 잔여 투자가능액
- 1차 기준가격
- TP1 / TP2
- 보유 거래일
- MAE(최대 불리 변동)
- 장기보유 위험검토
- 다음 행동

예:

```text
TQQQ

상태              2차 보유(HOLDING_2ND)
JDSS 점수         87 / 100
시장국면          YELLOW

평단              $86.40
현재가            $84.95
평가손익          -1.68%

1차 기준가격       $88.30
사이클 허용액       $8,000
단계매수 누적액     $2,800

다음 행동
3차 추가매수 감시

가격조건          <= $83.89
필요점수          >= 86
반등점수          >= 5
시장국면          RED 제외
```

## 13. 최종 승인 화면

실시간 가격을 다시 조회한 뒤 표시한다.

현재 주문 세션도 표시한다.

예:

```text
주문 가능시간       애프터마켓(After-Hours)
```

표시 항목:

```text
신호일
신호 종가
실시간 현재가
전략상 매수 허용 상한
최종 지정가
예정 투자금
수량
예상 매수수수료
예상 체결 후 평단
예상 TP1
예상 TP2
승인 유효시간
```

추가매수의 경우:

- 1차 기준가격
- 해당 단계 가격조건
- 현재가가 단계 가격조건을 여전히 만족하는지

도 반드시 표시한다.

버튼:

```text
[✅ 최종 매수 실행]
[❌ 취소]
```

## 14. 가격조건 이탈

### 1차 추격매수 제한

```text
⚠️ 매수 보류

신호 종가          $84.10
현재가             $86.30
추격매수 상한      $85.78

가격이 신호 이후 너무 상승했습니다.
현재 신호는 실행하지 않습니다.
```

### 추가매수 가격 회복

```text
⚠️ 추가매수 조건 해제

3차 가격조건       <= $83.89
현재가             $84.70

전일 종가에서는 조건을 만족했지만
현재 가격이 추가매수 기준 위로 회복했습니다.

추격해서 추가매수하지 않습니다.
```

## 21. `/panic`

일반 메뉴에는 노출하지 않는다.

```text
기존 매도주문 취소
↓
실제 잔고 확인
↓
비상매도 예상 수량 표시
↓
사용자 최종 확인
↓
시장가 전량매도
↓
실제 체결 확인
↓
DB/상태 정합성 점검
```

2단계 확인 필수.

## 22. `/setstate`

관리자용.

## 23. 오류 표시

### INFO(정보)

행동 불필요.

### WARNING(주의)

사용자 확인 권장.

### BLOCKED(매수 차단)

현재 신호 실행 불가.

### SAFE_MODE(안전모드)

신규 매수 전체 차단.

예:

```text
🛑 안전모드(SAFE_MODE)

TQQQ

증권사 실제수량     34주
DB 기록수량         32주

신규 매수가 차단되었습니다.
실제 잔고와 시스템 상태를 먼저 맞춰야 합니다.
```

## 25. 최종 UX 원칙

JDSS Telegram은:

> **알림은 충분히 제공하고, 실제 주문은 엄격하게 검증한다.**

사용자는 화면만 보고 다음 질문에 답할 수 있어야 한다.

- 지금 시장이 위험한가?
- 현재 JDSS 점수는 몇 점인가?
- 왜 매수 후보인가?
- 현재 얼마나 투자되어 있는가?
- 추가로 얼마까지 투자 가능한가?
- 다음 추가매수 가격은 얼마인가?
- 현재 가격이 아직 그 조건을 만족하는가?
- TP 주문은 정상인가?
- 재매수를 이미 사용했는가?
- 현재 내가 해야 할 행동이 있는가?

본 문서는 JDSS Telegram Bot v1.1.2의 공식 기준이다.
