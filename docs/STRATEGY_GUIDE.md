# JDSS 전략 가이드와 발전 이력

현재 개발 계약은 **JDSS-3.0.0-TWIN-H05**다. 정확한 수치와 실행 규칙은 [`JDSS_FINAL_SPEC.md`](JDSS_FINAL_SPEC.md)와 루트 `strategy.yaml`을 기준으로 한다.

## 현재 주력: V3 MONTHLY_H05

V3는 방향성이 강할 때 레버리지 ETF의 상승을 월간 코어로 따라가고, 급락 뒤 반등 기회는 작은 JDSS 부스터로 포착한다. 두 전략이 쓰지 않는 자금은 SGOV에 둔다.

- QQQ·SOXX 완료 월말 종가 > 각 10개월 이동평균: 대응 TQQQ·SOXL 코어 ON
- 코어 목표: 종목당 총 평가액 15%, 다음 거래일 조정
- JDSS 부스터: 종목당 `$1,000`, 초기 총자금의 최대 5%
- 코어·부스터 매수: Telegram 2단계 승인
- 코어 위험축소 매도: 자동
- 잔여자금: SGOV, 현금 버퍼 `$250`
- V3.0.0: dry-run 전용, live 코드 잠금

월간 주기를 선택한 이유는 PR #27 재검증에서 반월·격주 밴드 후보가 시작 위상과 표본에 민감했고 사전 승격 기준을 통과하지 못했기 때문이다. 더 복잡한 후보보다 비교 기준이었던 `MONTHLY_H05`가 규칙이 단순하고 위상 선택 편향이 없어서 첫 V3 dry-run 계약으로 적합했다. 자세한 연구 결과는 [`research/PR27_SIMPLE_STRATEGY_RESEARCH.md`](research/PR27_SIMPLE_STRATEGY_RESEARCH.md)에 남긴다.

## V2에서 V3로 바뀐 부분

| 항목 | V2.2.2 | V3.0.0 |
|---|---|---|
| 총자금 | 종목별 `$10,000` | 통합 `$20,000` |
| 주력 노출 | JDSS 단독 | 월간 코어 종목당 15% |
| JDSS 역할 | 종목별 전체 슬리브 | 종목별 `$1,000` H05 부스터 |
| 유휴자금 | SGOV | 코어·부스터 통합 후 잔여 SGOV |
| 원장 | 티커별 JDSS 포지션 | 코어·부스터 분리, 브로커 수량 합산 |
| live | 이중 확인으로 잠금 | 이번 버전은 전체 live 시작 자체 거부 |

## 유지된 JDSS 부스터 규칙

55점·반등 5점·RED 차단, 40/30/20/10 분할, -2/-5/-7% 추가매수, +4/+6% 익절, 20거래일 뒤 +2% 잔여청산, SOXL 섹터 가드, 자동손절·재매수 비활성화는 V2.2.2와 동일하다. 달라진 것은 종목별 자금 상한이 `$10,000`에서 `$1,000`으로 줄었다는 점이다.
